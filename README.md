# Weather App

Visit the site: https://krischalregmi.com.np/Weather-App/

The app can be installed from supported browsers when served over HTTPS (or localhost). Use the **Install app** button when it appears, or the browser's install option. The app shell is cached for offline launch, but fetching weather data still requires an internet connection.

The color theme follows the device preference until changed and is then saved in the browser. The page background also shifts subtly with the current weather.
